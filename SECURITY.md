# Security Policy

## Reporting a Vulnerability
If you discover a security issue in this project:
- Please open a **private security advisory** via GitHub Security tab.
- Do not open a public issue.
- Provide details of the vulnerability and steps to reproduce.

## Supported Versions
This project is actively maintained on the `main` branch.

## Commitments
- Dependencies are audited regularly.
- GitHub Secret Protection and Push Protection are enabled.
- No client or company data is included in this repository.
